Способ 1. Самый быстрый (через браузер)

1. Откройте нужный `.md` файл на сайте GitHub (например, `readme.md`).
2. В правом верхнем углу текстового блока найдите панель управления файлом и нажмите на **иконку с тремя точками `...`** (дополнительные действия).
3. В выпадающем меню выберите пункт **Download** (Скачать).  
    _Файл сразу скачается на компьютер в формате `.md`._

---

Способ 2. Через командную строку (Терминал)

Если вы хотите скачать Markdown-файл именно через консоль (например, `readme.md`, который лежит внутри папки `lecture`), выполните эти команды:

bash

```
# 1. Связываемся с проектом (если еще не сделали этого)
git clone --no-checkout https://github.com
cd development_of_a_software_application

# 2. Включаем правильный режим работы с путями
git sparse-checkout init --cone

# 3. Указываем путь к папке, в которой лежит ваш markdown
git sparse-checkout set lecture

# 4. Принудительно скачиваем файлы
git checkout -f main
```

Используйте код с осторожностью.

После этого в папке `lecture` на вашем компьютере появится файл `readme.md` (и `readme_1.md`, если вы скачивали `lecture/1`).

---

Способ 3. Для продвинутых (команда `curl`)

Если вам не хочется инициализировать Git, а нужен строго один файл через консоль, можно скачать его прямой ссылкой с серверов GitHub (Raw).

Введите в терминал (работает на Windows 10/11, macOS и Linux):

bash

```
curl -L -O https://githubusercontent.com
```

Используйте код с осторожностью.
